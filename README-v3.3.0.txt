Ask Jordan Core v3.3.0 — AI Safety & Trust

الجديد:
- فحص الإعلان قبل النشر بالذكاء الاصطناعي.
- Risk Score وTrust Score من 100.
- كشف تشابه الإعلان مع الإعلانات الحالية.
- تحويل الحالات المتوسطة إلى under_review بدل ظهورها مباشرة.
- منع الحالات عالية الخطورة تلقائيًا مع توضيح الأسباب.
- تخزين نتيجة الفحص وأسبابها ومرجع الإعلان المشابه.
- fallback محلي عند تعذر OpenAI.
- لوحة المشرف الحالية تعرض إعلانات under_review لاتخاذ القرار.

التثبيت:
1) شغّل upgrade-v3.3.0.sql داخل Supabase SQL Editor مرة واحدة.
2) ارفع كامل المشروع إلى Cloudflare.
3) تأكد من OPENAI_API_KEY في Cloudflare Secrets.
4) نفّذ Ctrl+F5 بعد النشر.

مهم:
الفحص مساعد آلي وليس إثباتًا قانونيًا للاحتيال. الإعلانات المشكوك فيها تذهب للمراجعة البشرية.
